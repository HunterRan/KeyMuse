KeyMuse

Keyboard & Mouse Automation Tool for Windows

Windows 键盘鼠标自动化工具

Features

Global Input Hooking

Low-level keyboard/mouse hooks via SetWindowsHookEx. Captures events system-wide with 500ms heartbeat health monitoring and auto-reconnect on failure.

Recording & Replay

Record events to .keymuse files (ZIP: session.json + events.bin). Replay with Single / N-times / Infinite loop modes.

Auto Clicker

Configurable interval auto-clicking (≥100ms). Trigger via VK_INSERT or toggle with F8.

Global Hotkeys

F6Toggle recording F7Play last recording / stop replay F8Toggle auto-clicker F9Emergency stop all F10Show/hide main window

Desktop UI

WPF main window with profile management, HUD overlay, system tray icon, and config import/export (.keymuse-profile).

Download

Pre-built binaries: GitHub Releases

Single-file self-contained executable (~155MB) — no runtime required.

Build from Source

Requires .NET 8.0 SDK and Windows 10+.

git clone https://github.com/HunterRan/KeyMuse.git
cd KeyMuse
dotnet restore
dotnet build --configuration Release
dotnet test
dotnet publish src/KeyMuse.Wpf/KeyMuse.Wpf.csproj -c Release -o ./publish

Architecture

KeyMuse.Core — hooking, recording, replay engine, auto-clicker, config

KeyMuse.Wpf — WPF desktop UI, tray icon, HUD, global hotkeys

功能特性

全局输入钩子

基于 SetWindowsHookEx 的低级键盘/鼠标钩子。500ms 心跳监控，断开自动重连。

录制与回放

录制事件到 .keymuse 文件（ZIP 格式：session.json + events.bin）。支持单次 / N 次 / 无限循环回放。

连点器

可配置间隔自动按键（≥100ms）。默认 VK_INSERT 触发，或按 F8 开关。

全局快捷键

F6录制 开始/停止 F7回放 上次录制/停止 F8连点 开关 F9急停 所有任务 F10窗口 显示/隐藏

桌面界面

WPF 主面板（配置管理、录制/回放控制）、HUD 叠加层、系统托盘图标、配置导入/导出。
